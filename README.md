# vibe-utilities
This repo contains internal utilities (scripts, tools etc) of the VIBE project.

## autobuild
This folder contains the scripts used to automatically build the application and desktop containers on Ubelix, the HPC of the university of Bern.

## desktop-scripts
These scripts are required for the VIBE desktop.

## vibe_logo
A python script used to create the logo of VIBE.
